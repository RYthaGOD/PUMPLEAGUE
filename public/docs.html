🏛️ Overview

PumpLeague is an automated token competition protocol on Solana. Every 24 hours, tokens battle based on their performance metrics, and the winners' holders receive SOL rewards directly to their wallets.

How It Works

  1. Registration — Token creators register their tokens to enter the arena
  2. Battle — Tokens are scored on fees, holder count, volume, and price stability
  3. Victory — Top 3 tokens win, and their holders receive SOL airdrops proportional to holdings

Scoring Weights

Metric Weight Description
Claimed Fees 30% SOL claimed from creator fees
Holder Count 25% Number of unique holders
24h Volume 20% Trading volume in last 24 hours
Price Stability 15% Lower volatility = higher score
Growth Rate 10% Holder and volume growth

Fee Distribution

  • 85% → Distributed to token holders
  • 10% → Arena fee (protocol)
  • 5% → Next round prize pool

⚡ API Reference

Access PumpLeague data programmatically. Public endpoints are available without authentication. For higher rate limits and webhooks, apply for an API key.

Base URL

https://api.pumpleague.com

Public Endpoints

GET /api/status

Protocol status and current configuration

GET /api/leaderboard

Current round token rankings

GET /api/rounds

Round history (add ?limit=10 for pagination)

GET /api/rounds/:id

Specific round details with payouts

GET /api/tokens

List all registered tokens

GET /api/hof

Hall of Fame — all-time champions

GET /api/stats

Aggregate protocol statistics

Authentication

For authenticated endpoints, include your API key in the header:

curl -H "X-API-Key: api_key_your_key_here" \
  https://api.pumpleague.com/api/status

Rate Limits

Tier Rate Limit Access
Public 100/hour Read-only public endpoints
Integration 1000/hour Full API + webhooks
Admin 5000/hour All access + key management

🔔 Webhooks

Receive real-time notifications when events occur. Requires an Integration tier API key.

Available Events

Event Trigger
round.started New competition round begins
round.completed Round finishes with payouts
token.registered New token enters competition
payout.sent SOL payment sent to holder
fraud.detected Suspicious activity flagged

Registering a Webhook

curl -X POST https://api.pumpleague.com/api/webhooks \
  -H "X-API-Key: api_key_your_key" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-server.com/webhook",
    "events": ["round.completed", "payout.sent"]
  }'

Webhook Payload

{
  "id": "evt_abc123",
  "type": "round.completed",
  "created": "2025-12-27T18:00:00Z",
  "data": {
    "round_id": "R20251227_1703689200",
    "total_fees_claimed": 2.5,
    "total_paid_out": 2.125,
    "winner_count": 3
  }
}

Signature Verification

All webhooks include an X-Webhook-Signature header. Verify it with HMAC-SHA256:

const crypto = require('crypto');

function verifyWebhook(payload, signature, secret) {
  const expected = 'sha256=' + crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify(payload))
    .digest('hex');
  
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}
